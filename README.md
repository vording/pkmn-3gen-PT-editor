# ポケットモンスターエメラルド　PT提案ツール

ポケモン第三世代（エメラルド／XD）の **後期シングル（6→3見せ合い・Lv50）** 向けのパーティ提案ツールです。
好きなポケモンを選ぶと、それを軸にした6体のパーティを提案します。
依存パッケージはなく、Node.js 18以上とブラウザだけで動きます。

```bash
npm start      # http://localhost:8080
npm test
npm run rank   # 独自ランクの作り直し（データ更新時）
```

## 使い方

1. 一覧から好きなポケモンを選ぶ（最大3体まで固定可。名前・タイプ・重要度で絞り込み）
2. 型を指定するか「おまかせ」にして「パーティを提案する」
3. 提案が3案出ます。各案には次の情報がつきます
   - 6体の型（持ち物・特性・性格・努力値・実数値・技）と、そのポケモンを採用した理由
   - おすすめ選出（6→3）
   - タイプ相性表、環境上位ポケモンとの対面表、弱点の警告
   - 共通するポケモンが多い構築例・大会パーティ
   - 「ぶっぱにするなら」：性格に合う252振り（AS/CS・HA/HC・HB・HD）の中から、仮想敵への有利度が一番高いものを提案（素早さで抜ける相手・有利／不利になる相手つき）。「この配分で見る」で実数値・調整の目安・画像・テキスト書き出しを切り替えられる（パーティの評価はそのまま）
   - 各ポケモンの「調整の目安」：素早さライン（どの仮想敵を抜けるか）、使用率の高い相手の技を何発耐えるか、相手を何発で倒せるか（乱数幅つき）
   - 戦い方：構築タイプ（鋼水／鋼水サンダー／グロスサンダー／格闘水）、勝ち筋、パーティ内の有名な組み合わせ、麻痺の使い方、先発と後ろ、各ポケモンの動かし方、相手のポケモン別の対応、枠のチェック、苦手な相手、ルール上の注意
   - テキスト書き出し・「画像で保存」（プレビューが開くので、スマホは長押し・PCは右クリックで保存。ダウンロードボタンもあり）
4. 気に入らない枠は「入れ替え候補を見る」で候補（評価の増減・得意な相手つき）を見て「これにする」で差し替えられます。「おまかせで入れ替え」なら一番評価の高い候補に差し替えます

## 提案のしくみ

| 要素 | 内容 |
| --- | --- |
| 仮想敵 | 2026年の大会で使われたポケモン（＋考察本の重要度☆☆以上）の代表的な型。使用率で重み付け |
| 対面評価 | 第三世代のダメージ式（タイプで物理/特殊が決まる・一致1.5倍・特性による無効や半減・ハチマキ・自爆の防御半減）による確定数、素早さ、状態異常技、カウンター、『だいばくはつ』や『みちづれ』による1:1交換、『なまけ』を考慮 |
| チーム評価 | 仮想敵ごとの最良の回答、同じタイプの弱点が3体以上重なるか、身代わり展開・バトンへの対策（ほえる・大爆発・せんせいのツメ・連続技・アンコール等）の有無、上位構築の4つの枠を満たすか、有名なコンボを含むか、眠り技の重複（眠らせられるのは1体まで）、構築例・大会パーティで一緒に採用された回数 |
| 探索 | ビームサーチで6体を選ぶ。道具の重複（アイテムクローズ）と禁止ポケモン・禁止道具は除外。2案目以降は前の案と違う顔ぶれを優先 |

対面評価は簡易モデルによる目安です。読み合いや交代戦までは考慮していません。

## ランク

一覧などに出るランク（S+〜E）は**このツール独自の評価**です。次を点数化し、順位で区切っています（S+:1〜3位、S:4〜8位、A:9〜18位、B:19〜32位、C:33〜50位、D:51〜80位、E:それ以降）。

| 要素 | 重み | 中身 |
| --- | --- | --- |
| 対面性能 | 0.5 | 仮想敵（使用率で重み付け）への平均有利度。型は上位3つのうち最良 |
| 環境での使われ方 | 0.35 | 2026年大会の使用率と入賞パーティでの使用率 |
| 考察本の重要度 | 0.15 | 最上位・☆☆☆・☆☆・☆ |
| 勝率補正 | ±0.05 | stoic氏ランクに載っているポケモンのみ |

stoic氏ランク・2026年大会の使用率・考察本の重要度は、バッジのツールチップと、選んだポケモンの詳細で確認できます。データを更新したら `npm run rank` でランクを作り直してください。提案の評価に使う「環境ランク」は stoic氏ランク（なければ考察本の重要度）のままです。

## データ

| データ | 出典 |
| --- | --- |
| 種族値・特性・考察本の重要度・型（技・持ち物・性格・努力値） | 『ポケモンエメラルドシングルバトル考察本』v1.4（全キャラ個別考察・最上位キャラ解説・努力値振りの倉庫）。正誤表（stoic氏ブログ 2026/11/15時点）を反映 |
| 2025〜26年の流行型（スプーンラティ、いばみがチイラプテラ、鈍いカウンターカビ、プンキネメタグロスなど） | すのーあのりす氏「GBA後期シングル 育成おすすめ」(2025/12)、stoic氏の構築記事（2026）、マイン氏の構築記事（2025） |
| 環境ランク（S+〜D）・勝率 | stoic氏「2026/08版 使用率・勝率に基づくGBAキャラランク」（2025/05〜2026/08 の大会） |
| 使用率・大会パーティ（101件、順位つき） | ポケモン第三世代KPアーカイブ（2026年の6大会） |
| くどオフ上位入賞構築（第1〜8回）・構築例 | 考察本「くどオフの記録」「パーティ図鑑」、上記ブログ記事の構築例 |
| 決勝進出カビゴンの型、構築タイプ別のゲンガーの型、サマヨール・アーボック・ゴローニャ・オオタチの配分案 | stoic氏ブログ（性格が書かれていない型は実数値から推定） |
| コンボ（ヘライコウ、グロスマンダ、ラティバシャプテラなど）、麻痺撒きの4作戦、上位構築の枠組み（対特殊／ノーマル耐性か格闘／鋼半減・地面等倍以下／格闘地面耐性）と構築タイプの分類、身代わり展開への対策 | stoic氏ブログ「GBA対戦コンビネーション集」「GBA麻痺撒き戦術まとめ」「上位入賞66構築の分類」「カビグロスサンダーの使い方・令和版」「GBA環境のコンボ対策」を要約 |

- 型は「最近の記事の型 → 考察本の型」の順に並べ、提案では上の型を少し優先します
- 仮想敵の重みは使用率の平方根、同時採用は構築例と大会パーティ（上位入賞は1.5倍）から数えています
- 努力値の記載がない型は、実数値から逆算するか、技構成から目安の配分を推定しています（推定時は画面に「目安」と表示）

ドット絵は [PokeAPI/sprites](https://github.com/PokeAPI/sprites) のエメラルド版スプライトを、表示時にブラウザから直接読み込んでいます（画像はリポジトリに含めていません）。オフラインなどで読み込めない場合は文字だけで表示されます。

## 構成

```
src/data/     図鑑・技・タイプ相性・ルール・参考構築
src/engine/   model.js（実数値・型）、matchup.js（ダメージ計算・対面評価）、recommend.js（提案）、analysis.js（調整の目安・戦い方）
src/ui/       ブラウザUI
test/         node:test によるテスト
```
