# 三世代式 対戦シミュレーター

第三世代（エメラルド世代）のバトル仕様を参考にした、**オリジナルモンスター**によるシングルバトルのシミュレーターです。
依存パッケージなし（Node.js 18+ とブラウザのみ）で動きます。

## 遊び方

```bash
npm start        # http://localhost:8080 を開く
npm test         # エンジンのテスト
```

1. 図鑑からモンスターを1〜6体選び、性格と技（各4つ）を設定
2. 「バトル開始！」で、同じ数のランダム編成の相手（AI）と対戦

## 実装している第三世代の仕様

| 項目 | 内容 |
| --- | --- |
| 実数値 | 第三世代の計算式（種族値・個体値・努力値・性格補正 1.1/0.9）。努力値は合計510まで |
| 物理/特殊 | 技のタイプで決まる（炎・水・草・電気・超能力・氷・竜・悪が特殊） |
| ダメージ計算 | 第三世代の式。乱数85〜100%、タイプ一致1.5倍、相性（17タイプ）、急所2倍（ランク無視の扱いも準拠） |
| 急所率 | 1/16 → 1/8 → 1/4 → 1/3 → 1/2 |
| 行動順 | 交代 → 技の優先度 → 素早さ（ランク・まひ1/4）→ 同速はランダム |
| 状態異常 | やけど（物理半減・1/8）、まひ（25%で行動不能）、どく（1/8）、もうどく（n/16）、ねむり（2〜5ターン）、こおり（20%で解凍・炎技で解凍） |
| 天気 | 雨・日差し（水/炎の威力補正）、砂嵐・あられ（1/16ダメージ）。技は5ターン、特性は無制限 |
| 能力ランク | ±6、命中・回避は第三世代の補正表 |
| その他 | PP、捨て鉢の一撃（PP切れ）、ひるみ、反動、吸収、ひんし後の交代 |

特性は「場に出たとき攻撃を下げる」「HP1/3以下で同タイプ技強化」「天気を呼ぶ」「接触でまひ」など12種類を実装しています。

## 構成

```
src/data/     タイプ相性・技・特性・モンスターのデータ
src/engine/   バトルエンジン（UIに依存しない純粋なJS）
  battle.js   ターン処理・状態異常・天気・特性
  damage.js   ダメージ計算
  stats.js    実数値・ランク補正
  ai.js       相手AI
  rng.js      シード付き乱数（同じシードで対戦を再現可能）
src/ui/       ブラウザUI
test/         node:test によるテスト
```

エンジンは単体でも使えます。

```js
import { Battle } from './src/engine/battle.js';
const battle = new Battle({ teams: [[{ species: 'hinokojika' }], [{ species: 'mizuchidori' }]], seed: 1 });
const events = battle.playTurn([{ type: 'move', index: 0 }, { type: 'move', index: 0 }]);
console.log(events.map((e) => e.text).filter(Boolean).join('\n'));
```

## データを増やすには

- モンスター: `src/data/species.js` に追加（`learnset` の先頭4つが初期技）
- 技: `src/data/moves.js` に追加（効果は `status` / `boosts` / `recoil` などのフィールドで指定）
